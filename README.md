# 生体荒野加强
对起源生体荒野进行了一些加强，修改了许多不合理的机制，同时尽可能确保贴近原版。

荒野可以使用更多的国民理念，诸如记念主义、创世共生等。为记念主义和催化加工国民理念添加了两个岗位变体以符合视觉效果。携带创世共生时，在环境改造后会为星球添加未开智物种，并且能正确获得表观遗传学触发器科技和对应的提升奖励。

荒野在选择物种飞升路线时，可以在中途选择克隆或变异的路线，但最后仍然必须选择纯净传统树。克隆可变传统1、3已经改为更加适合荒野的版本，前者会让再生源池提供额外的人口组装和减岗位维护费，后者会让孵育体减帝国规模效果。将纯净可变传统1的效果改为增加岗效，原本的减规模的效果移到可变传统3，可变传统3的+5尺寸移到纯净传统完成。删去了纯净传统完成时提供的区划无上限效果，但会加强荒野的领袖特质，根据主体物种的基因完美点数增加全国岗位产出和减少岗位维护费。

荒野在选择水之心飞升天赋并将星球改造为海洋星球，或选择星球塑形师飞升天赋并将星球改造为盖亚球后，可以获得区划无上限的效果，并且岗位数量变为原本的3倍。

生体荒野在选择飞升天赋巨兽之怒并进入五段，首都变为智链都会后，能够正确触发移识机制。为了平衡荒野过高的收益，将移识机制改为每6个月杀死全国1%的生物质。
